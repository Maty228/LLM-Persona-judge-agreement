# Agreement of LLM Judges in Persona Contradiction Detection

Statistical project for the course **Probability and Statistics I** investigating
agreement between large language models used as judges of persona consistency
in dialogue.

The experiment is based on PersonaChat and uses 1,000 matched dialogue pairs.
Each pair consists of:

- an original persona and dialogue,
- a contradiction-oriented augmented persona with the same dialogue.

Four LLM judges evaluate both versions, resulting in 2,000 examples and 8,000
binary judgments.

## Main files

- `report.md` — final statistical report
- `llm_judge_agreement.ipynb` — reproducible data preparation and statistical analysis
- `judge_config.py` — evaluation prompts and output parser
- `scripts/run_llm_judge.py` — LLM inference script
- `figures/` — figures generated by the statistical notebook

## Data

- `data/personachat_augmented_v2.parquet` — derived augmented PersonaChat dataset
- `data/llm_judge_experiment_v2.parquet` — frozen 1,000-pair experimental sample
- `data/llm_judge_pilot_v1.parquet` — frozen 50-pair subset used for prompt robustness
- `data/outputs/` — frozen LLM judgment files used by the statistical analysis

The LLM inference is computationally expensive and was performed separately on
GPU hardware. The saved judgment files are included so that the statistical
analysis can be reproduced without rerunning the language models.

## Dependencies

- `requirements.txt` — dependencies required for the statistical notebook
- `requirements-aic.txt` — dependencies required for GPU LLM inference

## Reproducing the statistical analysis

Install the notebook dependencies:

```bash
python -m pip install -r requirements.txt
```

Then open llm_judge_agreement.ipynb and run all cells from top to bottom.
The notebook reconstructs and validates the frozen experimental sample, loads
the saved LLM judgments, performs all statistical analyses, and generates the
figures used in the report.
The base dataset is PersonaChat:
Zhang, S., Dinan, E., Urbanek, J., Szlam, A., Kiela, D., & Weston, J. (2018).
Personalizing Dialogue Agents: I have a dog, do you have pets too?
Proceedings of ACL 2018.
[https://aclanthology.org/P18-1205/](https://aclanthology.org/P18-1205/)
